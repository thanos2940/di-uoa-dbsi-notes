Μία σελίδα για την πρόοδο

Πάτα Ctrl/Cmd+P για εκτύπωση (2 στήλες, χωρίς χρώματα). Το τελευταίο πράγμα που διαβάζεις πριν μπεις. Για βοήθημα μέσα στην αίθουσα: 🖨️ Τυπολόγιο A4.

💽 Δίσκοι & RAID
  • t = ts + tr + ttr· tr = ½·60.000/RPM ms· seek κυριαρχεί
  • τυχαία N·(…)· σειριακά ts+tr+N·ttr (16 s vs 38 ms για 1.000 μπλοκ)
  • SSD: read 25–50µs, write 200–500µs (10×), erase 2–5ms (100×)· WAF = φυσικά/λογικά
  • RAID χώρος D/(D+C): 0→100%, 1/0+1→50%, 2 (D=4,C=3)→57%, 3/4/5→80%, 6→66%
  • MTTF πίνακα = MTTF/N · parity′ = (old⊕new)⊕parity · RAID-5 parity κατανεμημένη · RAID-6 αντέχει 2 βλάβες
🧠 Buffer manager
  • ανά frame: BlockID, dirty, pin/rd-count, timestamp· pinned → όχι θύμα· dirty → γράψιμο πριν
  • LRU: παλαιότερο· CLOCK ≈ LRU με ref bit· MRU: πιο πρόσφατα unpinned· LRU-2: max(t−t2), t2=−∞ ⇒ ∞, ισοπαλία → νωρίτερο t1
  • Nested loop, R εξωτ., LRU, κοινή M: M ≥ p(S)+1 → p(R)+p(S), αλλιώς p(R)+p(R)p(S)
  • Πίνακας διάλεξης: R={A,B}, S={Γ,Δ,Ε,Ζ}, 2+2 πλαίσια → LRU 10, MRU 8, S εξωτ. 6
  • ΣΔΒΔ > ΛΣ: προβλέπει, prefetch, force-out, WAL, όχι διπλό buffering
📁 Αρχεία & σελίδες
  • RID = <page, slot>· heap: λίστες full/free ή page directory (4096/8 = 512 entries)
  • First / Best / Next-Fit / Append-only
  • διεύθυνση i = A+(i−1)μ· εγγραφές/μπλοκ = ⌊(M−hdr)/(μ+1bit)⌋
  • packed (συμπίεση αλλάζει RIDs) vs bitmap vs slotted <offset,len>, διαγραφή −1
  • Parquet: row-groups → column chunks → pages, footer min/max → predicate & projection pushdown
🔎 Ευρετήρια & κόστος
  • A1 εγγραφή · A2 <k,rid> · A3 <k,rid-list>· ≤1 clustered/πρωτεύον, πολλά δευτερεύοντα (πυκνά)
  • dense = όλες οι τιμές· sparse = μέρος, θέλει ταξινομημένο αρχείο, ψάξε μεγαλύτερο ≤ k
  • Heap: scan B(D+RC), ισότ. 0.5B(D+RC), ins 2D+C, del C+D
  • Sorted: ισότ. D·log₂B+C·log₂R, ins/del B(D+RC)
  • hash μόνο ισότητα· σύνθετο: η σειρά μετράει (<age,sal> για age=25 AND sal εύρος)
  • Επεκτατός: d′=D → διπλασιασμός, d′<D → μόνο split· κελιά ανά κάδο 2D−d′
🌳 B+ δέντρα
  • δείκτης δεξιά του K → τιμές ≥ K· όλα τα φύλλα ίδιο βάθος· κόμβοι ≥ 50%
  • εσωτερικός ⌈n/2⌉…n παιδιά, ≤ 2d κλειδιά· ρίζα ≥ 2 παιδιά
  • split φύλλου → COPY-UP· split εσωτερικού → PUSH-UP· σπάει ρίζα → ύψος +1
  • διαγραφή: δανεισμός (ενημέρωσε διαχωριστή) → αλλιώς συγχώνευση, διαχωριστής κατεβαίνει· άδεια ρίζα → ύψος −1
  • 3 δείκτες/2 τιμές, φύλλο 3 → min φύλλο 2, min εσωτ. 1 κλειδί
  • d: n·p+(n−1)k ≤ σελίδα (4096,12,8 → n=205, d=102)· h = ⌈logFN⌉
  • ISAM: στατικό, overflow pages, skew
📊 Εξωτερική ταξινόμηση
  • πέρασμα 0: ⌈N/B⌉ runs· merge B−1· #π = 1+⌈logB−1⌈N/B⌉⌉· κόστος 2N·#π
  • 2-way: 1+⌈log₂N⌉ (N=7 → 4)
  • N=108, B=5 → 22 → 6 → 2 → 1: 4 περάσματα, 864 I/O
  • 2 περάσματα αν B(B−1) ≥ N
  • replacement: B−2 set + in + out, runs ≈ 2B
  • B+ clustered → σάρωση φύλλων ✓· unclustered → ✗
✅ Checklist ετοιμότητας (Tier 1)
  • λύνω B+ «νέα ρίζα» εισαγωγής στο χαρτί
  • λύνω B+ «νέα ρίζα» διαγραφής (συγχωνεύσεις ως τη ρίζα)
  • υπολογίζω κόστος εμφωλιασμένων βρόχων με LRU για 4 τιμές του M
  • υπολογίζω runs/περάσματα/κόστος ταξινόμησης
  • συμπληρώνω πίνακα επεκτατού κατακερματισμού (D, μέγεθος, d′, περιεχόμενα)
  • γράφω από μνήμης: dense vs sparse, A1–A3, clustered, ISAM vs B+, LRU-2, RAID-4 vs 5
