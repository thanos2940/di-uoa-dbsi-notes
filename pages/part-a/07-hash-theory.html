Ο ΑΛΓΟΡΙΘΜΟΣ ΕΙΣΑΓΩΓΗΣ - Μηχανικά Βήματα

Βήμα 1: Βρες τον Κάδο

  1. Υπολόγισε: h(κλειδί) → binary
  2. Πάρε τα πρώτα D bits (MSB ή LSB ανάλογα την εκφώνηση)
  3. Μετέτρεψε σε δεκαδικό → αυτός είναι ο index στον κατάλογο
  4. Ακολούθησε τον pointer στον κάδο

Βήμα 2: Έλεγξε τον Κάδο

Χωράει; (< B στοιχεία;)

  • ✅ ΝΑΙ: Βάλε το στοιχείο. ΤΕΛΟΣ
  • ❌ ΟΧΙ: Πήγαινε στο Βήμα 3

Βήμα 3: Ο Κάδος είναι ΓΕΜΑΤΟΣ - Τι κάνω;

🎯 ΡΩΤΑ: d' < D ή d'=D;

📗 Περίπτωση A: d' < D

= SPLIT ΜΟΝΟ!

  1. Κάνε split τον κάδο
  2. d' του κάδου → d' + 1
  3. Μοίρασε τα στοιχεία ξανά
  4. Ενημέρωσε τους pointers

Ο κατάλογος ΔΕΝ αλλάζει!

📙 Περίπτωση B: d' = D

= DOUBLE + SPLIT!

  1. Διπλασίασε τον κατάλογο
  2. D → D + 1
  3. Κάνε split τον κάδο (d' + 1)
  4. Μοίρασε τα στοιχεία

Ο κατάλογος ΔΙΠΛΑΣΙΑΖΕΤΑΙ!

Βήμα 4: Μοίρασμα Στοιχείων μετά από Split

Μετά το split, πρέπει να ξαναμοιράσεις τα στοιχεία:

  • Κάθε στοιχείο κοιτάει τώρα d'+1 bits
  • Αν το νέο bit είναι 0 → Αριστερός κάδος
  • Αν το νέο bit είναι 1 → Δεξιός κάδος
⚠️ ΠΡΟΣΟΧΗ: Αν μετά το split όλα πάνε στον ίδιο κάδο, κάνε ΞΑΝΑ split!

ΠΛΗΡΕΣ ΠΑΡΑΔΕΙΓΜΑ: Εισαγωγή 5, 9, 14, 6, 7

B=2 (κάδος χωράει 2), h(x) = x mod 8 (3 bits), MSB

Αρχική Κατάσταση (D=1)
Βήμα 1: Εισαγωγή 5, 9

• h(5)=5=101 → MSB(1)=1 → Bucket 1
• h(9)=1=001 → MSB(1)=0 → Bucket 0

Βήμα 2: Εισαγωγή 14

• h(14)=6=110 → MSB(1)=1 → Bucket 1
• Χωράει! (1 στοιχείο ήδη, B=2)

⚠️ Βήμα 3: Εισαγωγή 6 - SPLIT!

• h(6)=6=110 → MSB(1)=1 → Bucket 1
• Bucket 1 είναι ΓΕΜΑΤΟ! d'=1, D=1 → d' = D → DOUBLE + SPLIT!

Σημείωση: Τώρα κοιτάμε τα 2 πρώτα bits!

📝 ULTRA-ΣΥΝΟΠΤΙΚΟ CHEAT SHEET

ΕΙΣΑΓΩΓΗ

1. h(key) → πάρε D bits
2. Πήγαινε στον κάδο
3. Χωράει; → ΤΕΛΟΣ
4. Κάδος γεμάτος!
   d' < D → SPLIT ONLY
   d' = D → DOUBLE + SPLIT

Η ΧΡΥΣΗ ΕΡΩΤΗΣΗ

d' < D ή d'=D;
  • d' < D: Split μόνο
  • d' = D: Double πρώτα!

ΤΥΠΟΙ

  • Μέγεθος καταλόγου: 2D
  • Pointers σε κάδο: 2D-d'
  • Πάντα: d' ≤ D

Γιατί Δυναμικός Κατακερματισμός;

Ο στατικός κατακερματισμός έχει σοβαρό πρόβλημα: Αν γεμίσουν οι κάδοι (buckets), δημιουργούνται αλυσίδες υπερχείλισης (overflow chains) που επιβραδύνουν την αναζήτηση.

Ο Επεκτατός Κατακερματισμός λύνει αυτό το πρόβλημα με έναν δυναμικό κατάλογο που μεγαλώνει/συρρικνώνεται όταν χρειάζεται, διατηρώντας σταθερό χρόνο αναζήτησης.

Intuition: Ο Δυναμικός Τηλεφωνικός Κατάλογος

Φαντάσου έναν τηλεφωνικό κατάλογο που:

  • Αρχικά χρησιμοποιεί μόνο το 1ο γράμμα του ονόματος (Α, Β, Γ...)
  • Αν γεμίσει μια κατηγορία (π.χ. "Α"), την διασπά σε "ΑΑ, ΑΒ, ΑΓ..." (χρησιμοποιεί και 2ο γράμμα)
  • Ο κατάλογος (index) διπλασιάζεται μόνο όταν χρειάζεται περισσότερα bits

Αυτό ακριβώς κάνει το Extendible Hashing με binary bits αντί για γράμματα!

1. Βασικές Έννοιες

Κατάλογος (Directory)

Ρόλος: Πίνακας που δείχνει σε ποιον κάδο να πας.

  • Μέγεθος: \(2^D\) εγγραφές (όπου \(D\) = Global Depth)
  • Κάθε εγγραφή: Pointer σε έναν κάδο
  • Πολλαπλά pointers μπορεί να δείχνουν στον ίδιο κάδο
Κλειδί: Ο κατάλογος είναι μικρός και μένει στη μνήμη. Μόνο 1 I/O για τον κάδο!

Κάδοι (Buckets)

Ρόλος: Αποθηκεύουν τα πραγματικά δεδομένα (records).

  • Χωρητικότητα: Κάθε κάδος χωράει \(B\) εγγραφές (π.χ. 4)
  • Local Depth \(d'\): Πόσα bits χρησιμοποιεί ο κάδος
  • Αν γεμίσει: Split (διάσπαση)

Global Depth vs Local Depth

Έννοια Ορισμός Τι καθορίζει
Global Depth (\(D\)) Πόσα bits χρησιμοποιούμε από το hash για να διαβάσουμε τον κατάλογο Μέγεθος καταλόγου = \(2^D\)
Local Depth (\(d'\)) Πόσα bits "κοιτάει" ένας συγκεκριμένος κάδος Πόσες εγγραφές καταλόγου δείχνουν σε αυτόν: \(2^{D-d'}\)
Σχέση: Πάντα \(d' \leq D\) για κάθε κάδο.
Αν \(d' < D\): Πολλά directory entries δείχνουν στον ίδιο κάδο (sharing).

2. Hash Function & Bit Extraction

Πώς λειτουργεί το Hashing

  1. Hash το κλειδί: \(h(K)\) → binary string (π.χ. "10110101")
  2. Πάρε τα πρώτα \(D\) bits: Αυτά χρησιμοποιούνται για τον κατάλογο
    • MSB (Most Significant Bits): Τα αριστερότερα bits (συνήθης επιλογή)
    • LSB (Least Significant Bits): Τα δεξιότερα bits
  3. Index: \(i = \text{binary to decimal}(\text{first } D \text{ bits})\)
  4. Πήγαινε: \(\text{Directory}[i]\) → Bucket
Παράδειγμα:
\(h(K) = 10110101\), \(D = 3\)
Παίρνω MSB: 10110101 → Index = 5
Πηγαίνω στο \(\text{Directory}[5]\)

3. Αλγόριθμος Εισαγωγής

Βήματα Εισαγωγής

Hashing & Directory Doubling Visualization

Εισάγετε τιμή. Χρήση MSB για τον κατάλογο.

Περίπτωση A: \(d' < D\)

Κατάσταση: Ο κάδος έχει "περιθώριο" να χρησιμοποιήσει περισσότερα bits.

Ενέργειες:

  1. Split Bucket: Δημιούργησε νέο κάδο
  2. Αύξησε Local Depth: \(d' \to d' + 1\) (και για τους δύο)
  3. Ανακατανομή: Μοίρασε τις εγγραφές βάσει του νέου bit (το \((d'+1)\)-οστό)
  4. Ενημέρωση Directory: Μισά pointers → παλιός κάδος, μισά → νέος κάδος
Όχι Directory Doubling! Ο κατάλογος δεν αλλάζει μέγεθος.

Περίπτωση B: \(d' = D\)

Κατάσταση: Ο κάδος χρησιμοποιεί ήδη όλα τα \(D\) bits. Χρειάζεται περισσότερα!

Ενέργειες:

  1. Double Directory: Διπλασίασε τον κατάλογο
    • \(D \to D + 1\)
    • Κάθε εγγραφή \(i\) γίνεται δύο: \(2i\) και \(2i+1\) (και οι δύο δείχνουν εκεί που έδειχνε το \(i\))
  2. Τώρα \(d' < D\)! Πήγαινε στην Περίπτωση A
Προσοχή: Μετά το doubling, ο κατάλογος διπλασιάστηκε, αλλά οι κάδοι όχι (ακόμα)!

Worked Example: Διαδοχικές Εισαγωγές

Σενάριο

Αρχική Κατάσταση: \(D = 2\), Κάδος χωρητικότητας \(B = 2\)

Κατάλογος:

00 → Bucket A (d'=2): [4, 8]    // hash: 00xxx
01 → Bucket B (d'=2): [5, 9]    // hash: 01xxx
10 → Bucket C (d'=2): [10]      // hash: 10xxx
11 → Bucket D (d'=2): [15]      // hash: 11xxx

Εισαγωγή: 21 (hash = 10101)

Βήμα 1: Πάρε MSB (2 bits): 10101 → Index = 2 → Bucket C

Βήμα 2: Bucket C έχει [10]. Προσθήκη 21 → [10, 21]. OK, χωράει!

Αποτέλεσμα: Bucket C = [10, 21]

Εισαγωγή: 26 (hash = 11010)

Βήμα 1: MSB: 11010 → Index = 3 → Bucket D

Βήμα 2: Bucket D έχει [15]. Προσθήκη 26 → [15, 26]. OK!

Εισαγωγή: 30 (hash = 11110)

Βήμα 1: MSB: 11110 → Index = 3 → Bucket D

Βήμα 2: Bucket D έχει [15, 26]. Προσθήκη 30 → OVERFLOW! (D γεμάτο: 3 εγγραφές > 2)

Βήμα 3: Έλεγχος: \(d' = 2\), \(D = 2\) → Περίπτωση B! (\(d' = D\))

Βήμα 4: Directory Doubling

  • \(D \to 3\)
  • Νέος κατάλογος (8 entries): 
    000 → A    100 → C
001 → B    101 → C
010 → A    110 → D
011 → B    111 → D  (όλα δείχνουν στα ίδια buckets)

Βήμα 5: Τώρα \(d' = 2 < D=3\) για το Bucket D → Περίπτωση A!

Βήμα 6: Split Bucket D

  • Νέα Local Depth: \(d' \to 3\) (και για D και για το νέο D')
  • Ανακατανομή με 3 bits:
    • Bucket D (110): [26] // hash 11010: MSB=110
    • Bucket D' (111): [15, 30] // hash 11XXX όπου 3ο bit = 1
  • Ενημέρωση καταλόγου: 
    110 → D (d'=3)
111 → D' (d'=3)
Τελικό Αποτέλεσμα: \(D = 3\), Directory = 8 entries, Split έγινε μόνο το Bucket D!

4. Τυπολόγιο & Formulas

Βασικοί Τύποι
Μέγεθος Καταλόγου: \(2^D\) entries
Pointers προς κάδο με \(d'\): \(2^{D - d'}\) directory entries
Κόστος Search: 1 I/O (κατάλογος στη μνήμη) + 1 I/O (bucket)
Worst-case Insertion: 2 I/Os (read + write bucket) + Directory update
Πότε Directory Doubling: Μόνο όταν \(d' = D\) για κάδο που γεμίζει

5. Κανόνες για Απομνημόνευση 🧠

Μνημονικό: "Split πρώτα, Double αν χρειάζεται"

✅ d' < D → Split Only

"Έχω χώρο → σπάω τον κάδο"

Ο κατάλογος ΔΕΝ αλλάζει μέγεθος!

⚡ d' = D → Double First!

"Θέλω περισσότερα bits → διπλασιάζω κατάλογο"

ΜΕΤΑ γίνεται d' < D → split κανονικά

Checklist Εξετάσεων

  • ☐ Πάντα δείξε το binary hash: π.χ. h(12) = 1100, MSB = 11
  • ☐ Γράψε το \(d'\) κάθε κάδου (δεν είναι όλα ίδια!)
  • ☐ Μετά από split: Αύξησε \(d'\) και στους ΔΥΟ νέους κάδους
  • ☐ Μετά από double: Αύξησε μόνο το \(D\), τα \(d'\) μένουν!
  • ☐ Formula check: Πόσα entries δείχνουν σε κάδο με \(d'\)? → \(2^{D-d'}\)

6. Exam Tips & Common Mistakes

Συχνά Λάθη
  • Μπερδεύεις \(D\) με \(d'\): Το \(D\) είναι global, το \(d'\) είναι per-bucket!
  • Directory doubling παντού: ΌΧΙ! Μόνο όταν \(d' = D\).
  • Ξεχνάς ποια pointers αλλάζουν: Μετά το split, ενημέρωσε μόνο τα σχετικά entries!
  • MSB vs LSB: Διάβασε την εκφώνηση! (Συνήθως MSB)
Στρατηγική Εξετάσεων
  • Πάντα σχεδίασε: Directory + Buckets με \(d'\) values
  • Δείξε το hash: Γράψε το binary και ποια bits παίρνεις
  • Βήμα-βήμα: Μετά από κάθε εισαγωγή, δείξε την κατάσταση
  • Ονοματολογία: Διάκρινε "Directory Entry" από "Bucket"

Βασική Διαφορά: Case A vs Case B

Case A: \(d' < D\)

Απλό Split
Δεν αγγίζουμε το Directory

Case B: \(d' = D\)

Double Directory πρώτα
Μετά κάνε Split (Case A)
