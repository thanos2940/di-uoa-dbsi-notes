Tuple-based Nested Loop

Για κάθε εγγραφή του R (outer), σαρώνουμε ολόκληρο τον S (inner).

Algorithm Logic
For each tuple r in R:
    For each tuple s in S:
        If r.val == s.val:
            Add <r, s> to result

Κόστος (Simple): \( p(R) + t(R) \cdot p(S) \)
