2. Μαγνητικός δίσκος (HDD)

Platter · τροχιά · κύλινδρος (ίδια τροχιά σε όλες τις επιφάνειες) · τομέας (256/512 B) · μπλοκ = 1+ τομείς = μονάδα I/O · 1 κεφαλή/επιφάνεια.

tI/O = ts + tr + ttr tr(μέσο) = ½ · 60.000 / RPM [ms] 5400→5,56 · 7200→4,17 · 10000→3 · 15000→2 ttr = μέγεθος μπλοκ / ρυθμός μεταφοράς τυχαία N μπλοκ: N·(ts+tr+ttr) σειριακά N: ts + tr + N·ttr

Seek κυριαρχεί. Μονάδες: 1 MB/s = 1 KB/ms (≈ με 1024).

Θέση επόμενου μπλοκ: ①ίδια τροχιά → ②ίδιος κύλινδρος (άλλη επιφάνεια) → ③διπλανός κύλινδρος, μετατοπισμένη αρχή.

Τεχνικές: track alignment, elevator scheduling, zoning, buffering, clustering, prefetch, WAL.

6. Εμφωλιασμένοι βρόχοι & πλαίσια

Αιτήσεις (R εξωτ.): R1, S1…Sp(S), R2, S1…, … → p(R)·(1+p(S)) αιτήσεις.

Κοινή μνήμη M, LRU: M ≥ p(S)+1 ⇒ p(R) + p(S) M ≤ p(S) ⇒ p(R) + p(R)·p(S) Block NL (κομμάτια M−2 του R, βιβλίο): p(R) + ⌈p(R)/(M−2)⌉·p(S)

MRU στον εσωτερικό που δεν χωρά: χάνεται μόνο ~1 θέση ανά γύρο. Μικρότερος πίνακας ως εσωτερικός αν χωρά ⇒ p(R)+p(S).

Ελέγξε: ζητούν αναγνώσεις μόνο ή και εγγραφή αποτελέσματος; Υπάρχει πλαίσιο εξόδου;

7. Disk space & αρχεία

Bitmap: 1 bit/μπλοκ (1 = κατειλημμένο), στη RAM. ΣΔΒΔ συχνά παρακάμπτει FS (φορητότητα, όρια μεγέθους).

Heap: λίστες full/free από header, ή page directory <pid, ελεύθερος χώρος>.

entries/dir-page = μέγεθος σελίδας / (|pid| + |ένδειξη|) π.χ. 4096 / (4+4) = 512

Επιλογή σελίδας: First-Fit · Best-Fit (λιγότερο κενό) · Next-Fit (από cursor) · Append-only.

RID = <page-id, slot>

8. Εγγραφές & πεδία

διεύθυνση εγγρ. i (σταθ. μ): A + (i−1)·μ διεύθυνση (μεταβλ.): A + Σk<i μk πεδίο i (σταθ.): base + Σk<i Lk εγγρ./μπλοκ (bitmap): ⌊ (M − hdr)·8 / (μ·8 + 1) ⌋ εγγρ./μπλοκ (χωρίς): ⌊ (M − hdr) / μ ⌋
  • Packed: hdr με n, διαγραφή ⇒ συμπίεση ⇒ αλλάζουν RIDs.
  • Bitmap: 1 bit ύπαρξης/slot, σταθερά RIDs.
  • Slotted: κατάλογος <offset,len> στο τέλος, κενό στη μέση, διαγραφή = −1.
  • Μεταβλ. πεδία: διαχωριστικό # · μήκος μπροστά · πίνακας offsets (NULL = μήκος 0).
  • Row-wise (slotted) vs column-wise· Parquet: row-groups → column chunks → pages, footer min/max (predicate & projection pushdown).

9. Ευρετήρια — ορισμοί

k*περιεχόμενο

  • Clustered: διάταξη εγγραφών ≈ διάταξη entries (≤ 1 ανά αρχείο).
  • Primary: στο πρωτεύον κλειδί, χωρίς διπλότυπα· secondary: άλλα πεδία· unique: χωρίς διπλότυπα.
  • Dense: entry για κάθε τιμή· sparse: για μερικές, θέλει ταξινομημένο αρχείο → μεγαλύτερο entry ≤ k και σάρωση.
  • Δευτερεύον ⇒ πυκνό· ζεύγη <τιμή, δείκτης> = #πλειάδων ανά ευρετήριο.
  • Σύνθετο κλειδί: η σειρά μετράει (ισότητα στο 1ο πεδίο, εύρος στο 2ο).
  • Hash: μόνο ισότητα. Δέντρο: ισότητα + εύρος.

11. Κατακερματισμός

Στατικός

h(x) = x mod k κάδοι (σταθερό k)· γεμάτος ⇒ σελίδες υπερχείλισης· αναζήτηση = 1 + μήκος αλυσίδας.

Επεκτατός (κατάλογος 2D)

κελί = πρώτα D bits (ή τελευταία — δες εκφώνηση!) κελιά που δείχνουν σε κάδο = 2^(D − d′) d′ από σχήμα: d′ = D − log₂(#κελιών κάδου)
  1. Βρες κάδο από τα D bits· αν χωρά → τέλος.
  2. Γεμάτος & d′ < D → split σε 2 κάδους με d′+1 (bit #d′+1), μοίρασε εγγραφές & δείκτες.
  3. Γεμάτος & d′ = D → διπλασίασε κατάλογο (D+1, κάθε κελί→2 ίδιοι δείκτες), μετά βήμα 2.
  4. Ξαναδοκίμασε (μπορεί >1 split).

Συμπλήρωσε: μέγεθος = 2D, βάθος D, #μπλοκ, d′ & περιεχόμενα ΜΟΝΟ όσων άλλαξαν.

12. ISAM & πολυεπίπεδα

Κόμβος: p0 k1 p1 k2 … kn pn· p0 → <k1, pi → [ki, ki+1).

Κατασκευή: ταξινόμησε → 1ο επίπεδο (αραιό, 1 entry/μπλοκ) → 2ο από το 1ο … ως 1 ρίζα.

n·(1/F)^h = 1 ⇒ h = logF n (+1 I/O για δεδομένα)

Στατικό: εισαγωγές → overflow pages· διαγραφές αφήνουν κλειδιά → skew. Outer (αραιό) πάνω από inner (πυκνό).

13. B+ δέντρο — ορισμός

  • Όλα τα φύλλα στο ίδιο βάθος· κόμβος = 1 μπλοκ = 1 I/O.
  • Εσωτερικός (όχι ρίζα): ⌈n/2⌉…n παιδιά, ≤ n−1 = 2d κλειδιά.
  • Φύλλα ≥ 50%· ρίζα (μη φύλλο) ≥ 2 παιδιά· φύλλα συνδεδεμένα (next).
  • P1 → < K1, Pi+1 → ≥ Ki (ίσο πάει ΔΕΞΙΑ).

14. B+ — εισαγωγή

  1. Κατέβα στο φύλλο L (≥ δεξιά). Βάλε το κλειδί ταξινομημένα.
  2. Χωρά → τέλος (εσωτ. κόμβοι ίδιοι).
  3. Υπερχείλιση φύλλου → split· COPY-UP το 1ο κλειδί του δεξιού (μένει κάτω).
  4. Γονέας υπερχειλίζει → split· PUSH-UP το μεσαίο (φεύγει από το επίπεδο).
  5. Σπάει η ρίζα → νέα ρίζα με 1 κλειδί, 2 παιδιά (ύψος +1).
φύλλο [a b c]+x→[a b][c x] ↑copy c εσωτ. [p q r]→[p][r] ↑push q

15. B+ — διαγραφή

  1. Βρες φύλλο, σβήσε. Αν ≥ min → τέλος (διαχωριστές ΜΕΝΟΥΝ).
  2. Υποχείλιση: δανεισμός από αδελφό (ίδιος γονέας) με > min → ενημέρωσε διαχωριστή = 1ο κλειδί δεξιού κόμβου.
  3. Αλλιώς συγχώνευση με αδελφό· σβήσε διαχωριστή από γονέα.
  4. Εσωτερικός υποχειλίζει: δανεισμός μέσω γονέα (διαχωριστής ↓, κλειδί αδελφού ↑) ή συγχώνευση (διαχωριστής ↓ μέσα στον νέο κόμβο).
  5. Ρίζα με 0 κλειδιά → αφαιρείται (ύψος −1).

Όλοι γεμάτοι ⇒ η εισαγωγή φτάνει στη ρίζα. Όλοι στο ελάχιστο ⇒ η διαγραφή φτάνει στη ρίζα.

16. B+ — λοιπά

  • Διπλότυπα: πολλά entries (ξεκίνα από αριστερότερο) ή (key, xid) ⇒ unique.
  • Prefix compression: στους εσωτ. αρκεί πρόθεμα που ξεχωρίζει (Lavigna/Lavrendi → «Lavr»).
  • Bulk loading: ταξινόμηση → εισαγωγή κατά σειρά (splits μόνο δεξί μονοπάτι) ή bottom-up.
  • B+ ως αρχείο (A1): εγγραφές στα φύλλα, clustered.

17. Εξωτερική ταξινόμηση

Πέρασμα 0: r₀ = ⌈N / B⌉ runs (μήκους B) Συγχώνευση: B−1 είσοδοι + 1 έξοδος #περασμάτων = 1 + ⌈logB−1 r₀⌉ κόστος = 2·N·#περασμάτων (αν δεν γράφεις το τελικό: 2N·#π − N) 2-way (3 πλαίσια): 1 + ⌈log₂ N⌉ 2 περάσματα ⇔ ⌈N/B⌉ ≤ B−1 (≈ N ≤ B(B−1))

Βήμα-βήμα: r → ⌈r/(B−1)⌉ → … → 1 (μέτρα βήματα).

Η διαφάνεια γράφει και ⌈N/(B−1)⌉ για r₀ — συνήθως ίδιο αποτέλεσμα· γράψε ποιο χρησιμοποιείς.

Replacement sort

B−2 current set + 1 input + 1 output· βγάζεις το μικρότερο ≥ l (τελευταίο έξοδο)· κανένα ≥ l ⇒ νέο run. Τυχαία: runs ≈ 2B· ταξινομημένη: 1 run· φθίνουσα: ελάχιστα.

Double buffering: shadow buffers, CPU ∥ I/O. B+ για sort: clustered ✓ · unclustered ✗.
